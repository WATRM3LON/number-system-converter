2. System Algorithms & Pseudocode

Algorithm 1: Base Input Digit Validation

FUNCTION ValidateInput(numberStr, base): IF numberStr IS EMPTY: RETURN False, "Input cannot be empty" SET validChars = GET_ALLOWED_DIGITS(base) // e.g. Base 2 -> [0,1], Base 8 -> [0-7] SET parts = SPLIT(numberStr, '.') IF LENGTH(parts) > 2: RETURN False, "Multiple radix points detected" FOR EACH char IN numberStr: IF char != '.' AND char NOT IN validChars: RETURN False, "Invalid digit '" + char + "' for Base " + base RETURN True, "Valid" END FUNCTION

Algorithm 2: Any Base to Base-10 Decimal Conversion (Integer + Fraction)

FUNCTION ConvertToBase10(numberStr, sourceBase): SET [intPart, fracPart] = SPLIT(numberStr, '.') SET decimalVal = 0 // Integer Part Positional Expansion: sum(digit * base^i) SET len = LENGTH(intPart) FOR i FROM 0 TO len - 1: SET digit = DIGIT_VALUE(intPart[len - 1 - i]) decimalVal = decimalVal + (digit * (sourceBase ^ i)) // Fractional Part Radix Expansion: sum(digit * base^-j) IF fracPart EXISTS: FOR j FROM 1 TO LENGTH(fracPart): SET digit = DIGIT_VALUE(fracPart[j - 1]) decimalVal = decimalVal + (digit * (sourceBase ^ -j)) RETURN decimalVal END FUNCTION

Algorithm 3: Decimal to Target Base Conversion

FUNCTION ConvertFromDecimal(decimalValue, targetBase, maxFracDigits = 8): SET intPart = FLOOR(decimalValue) SET fracPart = decimalValue - intPart // Convert Integer via Repeated Division SET intResult = "" WHILE intPart > 0: SET rem = intPart MOD targetBase intResult = GET_DIGIT_CHAR(rem) + intResult intPart = FLOOR(intPart / targetBase) IF intResult IS EMPTY: intResult = "0" // Convert Fraction via Repeated Multiplication IF fracPart == 0: RETURN intResult SET fracResult = "." SET count = 0 WHILE fracPart > 0 AND count < maxFracDigits: fracPart=fracPart * targetBase SET digit=FLOOR(fracPart) fracResult=fracResult + GET_DIGIT_CHAR(digit) fracPart=fracPart - digit count=count + 1 RETURN intResult + fracResult END FUNCTION

Algorithm 4: Shunting-Yard Infix to Postfix (RPN) Expression Parser

FUNCTION ShuntingYardParser(expressionStr, validVariables): SET tokens = TOKENIZE(expressionStr) SET outputQueue = [] SET operatorStack = [] FOR EACH token IN tokens: IF token IS NUMBER OR token IN validVariables: ENQUEUE(outputQueue, token) ELSE IF token IS OPERATOR (op1): WHILE operatorStack HAS OPERATOR (op2) AND op2 != '(' AND (PREF(op1) <= PREF(op2) AND ASSOC(op1)=='L' ): ENQUEUE(outputQueue, POP(operatorStack)) PUSH(operatorStack, op1) ELSE IF token=='(' : PUSH(operatorStack, '(' ) ELSE IF token==')' : WHILE TOP(operatorStack) !='(' : IF operatorStack IS EMPTY: ERROR("Mismatched parentheses: unexpected ')'") ENQUEUE(outputQueue, POP(operatorStack)) POP(operatorStack) // Discard matching '(' WHILE operatorStack IS NOT EMPTY: IF TOP(operatorStack) == '(': ERROR(" Mismatched parentheses: missing ')'") ENQUEUE(outputQueue, POP(operatorStack)) RETURN outputQueue END FUNCTION

Algorithm 5: Postfix RPN Evaluator with Arithmetic Error Trapping

FUNCTION EvaluateRPN(rpnQueue, variableValues): SET evalStack = [] FOR EACH token IN rpnQueue: IF token IN variableValues: PUSH(evalStack, variableValues[token].decimalValue) ELSE IF token IS NUMBER: PUSH(evalStack, PARSE_FLOAT(token)) ELSE IF token IS OPERATOR (op): IF LENGTH(evalStack) < 2: ERROR("Syntax error: missing operands") SET b=POP(evalStack) SET a=POP(evalStack) // Arithmetic Error Handling: Division by Zero IF op=='/' AND ABS(b) < 1e-12: ERROR("Arithmetic Error: Division by zero encountered (" + a + " / " + b + ")" ) SET result=COMPUTE_OP(op, a, b) PUSH(evalStack, result) IF LENGTH(evalStack) !=1: ERROR("Syntax error: invalid expression") RETURN POP(evalStack) END FUNCTION

4. Program Implementation & Architecture

The application is implemented in clean modular JavaScript (ES6+), Vanilla CSS3, and HTML5 using event-driven reactive DOM updates.

Data Structures

// Input Object Representation const inputModel = { id: "input-1", rawString: "1010.1", base: 2, // 2, 8, 10, or 16 isValid: true, decimalVal: 10.5 }; // Arithmetic Evaluation Pipeline const arithmeticResult = { expressionStr: "1010.1₂ + 17₈ + 15₁₀", operation: "+", decimalResult: 40.5, converted: { binary: "101000.1", octal: "50.4", decimal: "40.5", hexadecimal: "28.8" } };

Core Code Modules

• validateBaseInput(str, base): Uses RegExp pattern matching matching ^[0-1]+$ (Bin), ^[0-7]+$ (Oct), ^[0-9]+$ (Dec), and ^[0-9A-Fa-f]+$ (Hex).
• convertToDecimal(str, base): Evaluates integer summation \(\sum d_i \cdot b^i\) and fraction summation \(\sum d_j \cdot b^{-j}\).
• convertFromDecimal(val, targetBase): Repeated division for integer part and radix multiplication for fractional part.
• evaluateExpression(inputs, operation): Performs sequential left-to-right evaluation across input decimal values.
